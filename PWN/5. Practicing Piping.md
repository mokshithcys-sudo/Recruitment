## Redirecting errors
In this level we need to redirect two outputs to two different locations.\
Here we can use the > and 2> method, in this case one output is redirected \
to the file mentioned after > and  the other output to the file mentioned after 2>\
The command i used here is /challenge/run > myflag 2> instructions, here flag is \
redirected to myflag and error is redirected to the file instructions.\
And i used cat myflag to get the flag.\
